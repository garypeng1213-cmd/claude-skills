# 更新紀錄

## 2026-09-25：同步上游 2026-09-23 修訂

上游 [op7418/Humanizer-zh](https://github.com/op7418/Humanizer-zh) 在 2026-09-23 發布 commit `f4518a8`（fix: preserve meaning and author voice in Chinese rewrites），處理「文章改順了，意思卻變了」的問題。該修訂以 [blader/humanizer v3.0.0](https://github.com/blader/humanizer/blob/v3.0.0/SKILL.md) 與 [PR #39](https://github.com/op7418/Humanizer-zh/pull/39) 為基礎。本版依此繁體化，並保留本 repo 的在地化內容。

### 自上游納入

- 明確要求保留事實、數字、否定、條件、時間、歸因和作者態度。「可能」不能改成「確定」，「大家覺得」不能改成「我以前覺得」。
- 規則改為 31 個檢查點：A–E 組 25 條對齊 blader v3.0.0，F 組 6 條是中文專屬檢查點。每條都補上適用條件，以及應該保留的表達。
- 修正舊範例憑空添加產品功能、研究數據、人物經歷等問題。原文沒有的資訊，不用潤飾補出來。
- 不再依詞語、標點或列舉數量機械修改。真實的三項功能、必要的破折號、中文排比和連接詞可以保留。
- 依作者樣本和文體處理：技術說明、商務報告和個人隨筆分別對待，不統一改成聊天語氣。
- 檔案模式明確保護程式碼、指令、路徑、連結、YAML、標題和錨點；預設只交付最終稿。
- 新增 `tests/`：18 個短文字案例、一份 Markdown 檔案樣例，以及唯讀的結構檢查腳本。

### 本 repo 的在地化與保留

- 全文轉為繁體中文與台灣用語（例如「匯出」、「快取」、「記憶體」、「週三」），範例中的城市改為台北。
- §21 改以台灣慣用的「」為主要引號、『』為內層；使用者指定時，才保留 “” 樣式。
- §12 的「保留」範例改用台灣常見的工程術語「無縫鋼管」。
- 保留與 `text-watermark-cleaner-zh-tw` 的分工：需求分類、合併流程，以及完成後的選擇性詢問。作為其他任務的一個步驟時，不做這項詢問。
- 保留「繁體字、全形標點與空白語意不變，不擅自簡繁轉換」的要求。
- 50 分品質評分改為「僅在使用者明確要求時」提供，並註明不能取代事實與語意核對。上游已完全移除這項評分。
- 舊版的「個性與靈魂」、「核心規則速查」、「快速檢查清單」，由「文體與作者聲音」、「編輯約束與優先順序」、「交付前核對」取代。README 的「常見 AI 詞彙警示列表」移除，因為新規則不把詞表當成黑名單。
- `tests/` 的案例與樣例轉為繁體與台灣用語；`check_structure.py` 的邏輯與上游相同，只補上中文註解。
- README 新增「用 hook 自動驗證（選用）」：說明 Claude Code、Codex CLI、Gemini CLI、Antigravity、Cursor、Windsurf、GitHub Copilot 與 Git pre-commit 的 hook 設定位置、事件與回報方式。只有說明，不附腳本或設定檔。

### 安裝說明

- npx skills 安裝指令加上 `--full-depth`，讓子資料夾中的 `text-watermark-cleaner-zh-tw` 也能被找到；另外補上只安裝其中一個 skill 的指令。目錄結構不變，與上游同步時的路徑維持一致。
- 移除 Roo Code 的安裝指令。Roo Code 擴充功能已於 2026-05-15 停止服務，GitHub repo 也已封存。
- `.gitignore` 加入 `__pycache__/`。

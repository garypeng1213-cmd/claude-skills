## 遇到的問題與修法

| 問題 | 原因 | 修法 |
|---|---|---|
| 鋼軌外框算不出來 | 一個斷面由多條路徑組成，還有曲線 | `grow()` 收集相連路徑，端點吸附，貝茲攤平，polygonize 後取聯集 |
| 鋼軌圖塊太多種 | 微小誤差 | Hausdorff < 1 cm 視為同形，7 種 → 5 種 |
| 被切開的尺寸數字重複出現 | 文字迴圈沒跳過已做成 DIMENSION 的子鍵 | 尺寸鍵（含 `9.0` 這類子鍵）在文字迴圈中略過 |
| CTB 出 2.11 mm 粗線、檔案損壞 | ezdxf `save()` 的 bug | 自寫檔頭；線寬改成標準索引（見 ctb.md） |
| CTB 出圖不是黑色 | color_policy 不對 | `color=-16777216`、`color_policy=5` |
| -PLOT 選不到 CTB | 中文檔名 | 改用 ASCII 檔名 `P17-LW.ctb` |
| DIMREASSOCIATE 多數失敗 | 用了透明 zoom；定義點不在幾何上 | 每道先 ZOOM W；OSOPTIONS 7；用射線找吸附點 |
| 關聯後一道標註量測值變 0 | 第一點吸到錯的幾何 | 解除關聯，改回 13/14，只關聯第二點 |
| **6 處尺寸數字跑位**（審查時發現） | AutoCAD 開檔或關聯後自動重排文字 | group 11 設成原圖位置，70 \|= 128 |
| **2 條尺寸線位置錯**（審查時發現） | 關聯時尺寸線被移動：一條壓到說明文字上，一條偏右約 4.6 mm | 改 group 10 |
| -PLOT 卡在「是否繼續打印」 | 在模型頁執行 | 先 `(setvar "CTAB" (car (layoutlist)))` |
| 審查時以為漏了「少」字 | 比對截圖裁切到字 | 300 dpi 放大原圖和新圖並排確認 |

## 審查方法（`scripts/review2.py`）

1. 原圖和新圖都用 200 dpi 灰階點陣化，門檻 < 200 視為有墨。
2. 漏畫：原圖有墨、新圖（膨脹 4 px）沒有。
3. 多畫或位置錯：反過來比。
4. 每處差異做成「左原圖、右新圖」的對照拼圖（`rev_missing.png`、`rev_extra.png`），再對可疑處用 300 dpi 放大。
5. 每處歸類：
   - 漏畫 → 修
   - 位置錯 → 修
   - 字型字形差異（原圖字型和 LiSongPro 不同，標題字水平偏 2~3 pt）→ 可接受，回報
   - 虛線相位 → 可接受，回報
6. 用 PDF 文字抽取比對每段文字的中心座標，找出跑位的文字。
